# Local video input

Place the assessment video here as:

```text
data/raw/TestVidTask.mov
```

The video, extracted frames, and annotated-video derivatives are intentionally
excluded from version control. The public repository contains only scripts,
audited numerical outputs, and non-pixel trajectory schematics.

Do not place review crops, contact sheets, evidence packets, faces, appearance
features, or identity embeddings in Git. Follow the retention/deletion and
release gate in
[`docs/privacy_and_data_governance.md`](../../docs/privacy_and_data_governance.md).
